## 개요

상품 필터 옵션이 대략 20개 가량 되는데 대량의 옵션이라서 `useState`가 아닌 `zustand` store로 상태 관리를 하려고 한다

근데 `zustand`로만 관리를 하면 불필요하게 전역 상태 관리가 이루어지기 때문에
`context provider`와 결합하여 **컴포넌트 상태 관리** 로직을 만들겠다

## 검색어 로직 구현

![[Pasted image 20260930182503.png]]

![[Pasted image 20260930182509.png]]

현재 검색 버튼을 눌러야 검색어를 검색하는 UI인데 `query`에 input의 value를 바로 바인딩하면 
해당 UI와 맞지 않으므로 `query`를 `viewQuery`에 따로 저장하고 **검색 버튼**을 클릭 했을 시에 로직이 작동하도록 구성한다. 

또한 사용자가 `Enter`를 눌렀을 시에도 검색 로직이 작동하도록 `form`의 `submit`을 활용한다.

## 무한 스크롤 페이지네이션

![[Pasted image 20260930180842.png]]

![[Pasted image 20260930180908.png]]
