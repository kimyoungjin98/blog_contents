## useState 로직

### use-state.ts

```ts
const states: unknown[] = [];

let hookIndex = 0;

  

export function useState<T>(initialValue: T): [T, (newValue: T) => void] {

  const currentIndex = hookIndex;

  

  // hookIndex를 증가시켜 다음 useState 호출 시 다른 인덱스를 사용하도록 함

  hookIndex++;

  

  // states 배열에 현재 인덱스에 해당하는 값이 없으면 초기값을 설정

  if (states[currentIndex] === undefined) {

    states[currentIndex] = initialValue;

  }

  

  const state = states[currentIndex] as T;

  const setState = (newValue: T) => {

    states[currentIndex] = newValue;

  };

  

  return [state, setState];

}
```

화면에서 버튼을 하염없이 클릭 해보았지만 값과 화면은 변하지 않았다.

이유는 
1. 상태만 바뀌고 화면을 다시 그리지 않음
2. 클릭할 때마다 같은 값 저장
3. 재실행 전에 hookIndex를 초기화 해줘야함

### 수정본
```ts
const states: unknown[] = [];

let hookIndex = 0;

  

export function registerRerenderCallback(callback: () => void) {

  // 상태가 변경될 때마다 호출되는 콜백을 등록하는 로직을 구현할 수 있습니다.

  // 예를 들어, 상태 변경 시 UI를 다시 렌더링하도록 설정할 수 있습니다.

  // 이 예제에서는 간단히 콘솔에 메시지를 출력하도록 합니다.

  callback();

}

  

export function resetHookIndex() {

  hookIndex = 0;

}

  

export function useState<T>(initialValue: T): [T, (newValue: T) => void] {

  const currentIndex = hookIndex++;

  

  // 현재 인덱스에 해당하는 상태가 존재하지 않으면 초기값으로 설정

  if (!(currentIndex in states)) {

    states[currentIndex] = initialValue;

  }

  

  const state = states[currentIndex] as T;

  const setState = (newValue: T) => {

    states[currentIndex] = newValue;

  };

  

  return [state, setState];

}
```

## 다중 컴포넌트 지원하기

### use-state.ts
```ts
let currentComponentInstance: ComponentInstance | null = null;

  

// functional component를 호출할 때마다 새로운 ComponentInstance를 생성하고,

// 해당 인스턴스를 currentComponentInstance에 설정합니다.

// 그리고 functional component의 렌더링이 끝나면 이전 인스턴스로 되돌립니다.

export function withComponentInstance<T>(

  instance: ComponentInstance,

  callback: () => T,

): T {

  const previous = currentComponentInstance;

  currentComponentInstance = instance;

  instance.hookIndex = 0;

  

  try {

    return callback();

  } finally {

    currentComponentInstance = previous;

  }

}
```

`withComponentInstance` 함수를 선언하여 함수형 컴포넌트 마운트 시에 인스턴스를 초기화 하도록 작성한다

### render.ts > render()

```ts
if (element.type instanceof Function) {

    const Component = element.type;

  

    // ComponentInstance를 관리하기 위해 전달받은 키를 사용

    const instanceKey = element.props._componentInstanceKey;

    if (instanceKey === undefined) {

      throw new Error("함수 컴포넌트에 _componentInstanceKey를 전달해야 합니다.");

    }

  

    // instanceMap에서 ComponentInstance 가져오기, 없으면 새로 생성

    let instance = instanceMap.get(instanceKey);

    if (!instance) {

      instance = { states: [], hookIndex: 0 };

      instanceMap.set(instanceKey, instance);

    }

  

    const child = withComponentInstance(instance, () =>

      Component(element.props),

    );

    render(child, container);

    return;

  }
```

그 후 `Functional component` 일 때 instance를 map으로 저장해서 각각의 컴포넌트에서 다른 `state`를 사용할 수 있도록 작성해준다.
