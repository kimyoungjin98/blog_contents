최근에 앱인토스로 '<font color="#f79646">프레시킵</font>' 이라는 사진 촬영 또는 직접 식품을 등록하여 유통기한을 사용자에게 알려주는 서비스를 만들었다.

해당 서비스의 핵심 로직 중에 OCR 로직이 있는데, 사진 선택 후 '분석 중' 이라는 페이지에서 로딩 후 분석이 완료되면 나머지 값을 입력하는 창으로 이동하는 로직이다.

![[Pasted image 20260922183048.png]]![[Pasted image 20260922183150.png]]

근데 만들고 앱을 몇번 써보니까 OCR 분석이 느린 속도는 아닌데 해당 UI가 중간에 껴있으니까 뭔가 느린 것 같다는 생각이 들었다

이걸 어떻게 해결할까 하다가 최근에 최적화 관련해서 기술 서치를 했었는데 그 중에 '<font color="#4f81bd">낙관적 UI 업데이트</font>' 라는 기술에 대하여 읽었던게 기억이 났고 여기에서 영감을 얻어 

일단 분석이 끝나지 않아도 입력 form으로 이동시키는게 UX적으로 더 나을 것 같다는 생각이 들었다.


![[Pasted image 20260922185442.png]]![[Pasted image 20260922185448.png]]

수정을 하고 사용을 해봤는데 아직 로딩이 지연되는 건 동일하지만 넘어가야 할 화면이 하나 줄어듦으로써 그 전 로직보다 빨라진 것 같은 느낌을 받았다
