## 카드 UI

다음으로는 **상품 카드 UI**를 다듬어보자

![[Pasted image 20260930141213.png]]

일단 목업 이미지를 `picsum`의 랜덤 이미지로 교체해주고 (추후에 로딩 state 구현을 위함)

이번에도 역시 레퍼런스를 가져와서 UI를 고민해보자

- 토스 쇼핑
![[Pasted image 20260930141351.png]]

- 쿠팡
![[Pasted image 20260930141426.png]]

- 네이버 스토어
![[Pasted image 20260930141504.png]]


일단 레퍼런스들의 공통점은 
- 정보의 밀도가 낮다
- 다른 정보들보다 **가격**에 시선을 집중시키는 UI

두 가지의 특징을 살려서 현재 카드 UI를 조금 다듬어보겠다


![[Pasted image 20260930142328.png]]

- 밀도 낮추기
- 상품명의 `font-size` 와 `font-weight`를 한 단계씩 낮추기

두 가지 사항을 반영해주고 

현재 카드 UI를 보면 정보칸의 최상단에 불필요하게 브랜드명이 노출이 되고있는데 해당 정보는 없어도 될 것 같아 제거 해주고 최하단의 뱃지는 조금 더 스타일링을 해줘야 될 것 같다

![[Pasted image 20260930143045.png]]

- 정보 계층 안 패딩 조정
- 뱃지 스타일링
- 브랜드명 제거

세 가지 사항을 반영해주었다

![[Pasted image 20260930143133.png]]
