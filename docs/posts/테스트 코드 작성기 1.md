## 기본 구조

`describe` : 테스트 그룹
`it / test` : 개별 테스트 케이스
- 첫 번째 인자는 설명, 두 번째 인자는 콜백함수
`expect` : 검증
- `expect(실제값)` **matcher**를 이어 붙여 "해당 값은 이래야 한다"를 선언한다.

```ts
import { describe, it, expect, test } from 'vitest'
import { add } from './add'

describe('add', () => {
  it('두 수를 더한다', () => {
    expect(add(1, 2)).toBe(3)
  })

  test('음수도 처리한다', () => {
    expect(add(-1, -2)).toBe(-3)
  })
})
```


## 비동기 테스트

```ts
it('async/await', async () => {
  const data = await fetchData()
  expect(data).toBe('ok')
})

it('resolves / rejects', async () => {
  await expect(fetchData()).resolves.toBe('ok')
  await expect(failing()).rejects.toThrow('fail')
})
```


## 라이프 사이클 훅

```ts
import { beforeAll, afterAll, beforeEach, afterEach } from 'vitest'

beforeAll(() => {})   // describe 시작 전 1회
afterAll(() => {})    // describe 종료 후 1회
beforeEach(() => {})  // 각 테스트 전
afterEach(() => {})   // 각 테스트 후
```


## 테스트 제어

```ts
it.skip('건너뛰기', () => {})
it.only('이것만 실행', () => {})
it.todo('나중에 작성')
it.fails('실패해야 통과', () => {})
it.concurrent('병렬 실행', async () => {})

// 파라미터화
it.each([
  [1, 1, 2],
  [2, 3, 5],
])('add(%i, %i) = %i', (a, b, expected) => {
  expect(add(a, b)).toBe(expected)
})
```
