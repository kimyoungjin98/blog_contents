## 개요

![[Pasted image 20260929135019.png]]

현재 서버에서 모의데이터를 받아와서 화면에 렌더링 하고있는데
변동 되었을때 어떤값이 방금 변경되었는지 확인할 수 있어야 될 것 같아서
레퍼런스를 찾아 토스 증권을 들어갔는데 

![[Pasted image 20260929135135.png]]

등락률이 변경되었을 때 배경색에 트랜지션을 줘서 확인이 가능하다

## 구현

![[Pasted image 20260929135517.png]]

![[Pasted image 20260929135539.png]]

먼저 배경색을 보여주기 위한 컨테이너를 만들고 약간의 디자인을 추가했다

![[Pasted image 20260929140046.png]]

이제 배경색을 위한 flag 로직을 추가했는데 해당 로직은 변동된 UI가 사라지지 않아서

![[Pasted image 20260929140125.png]]

위와 같이 계속 남아있게되어 의미가 없어진다

![[Pasted image 20260929140555.png]]

배경색이 바뀌었다가 다시 원래대로 돌아오는 애니메이션을 선언한 후

![[Pasted image 20260929140616.png]]

그대로 `className`에 적용해주면 간단하게 구현이 완료된다

![[Pasted image 20260929140654.png]]

근데 한 가지 더 해결해야 할 것이 있다
현재는 `changeRate`를 음수/양수로만 구분을 해서 해당 UI를 표출하기 때문에
양수에서 변동값이 아무리 바뀌어봤자 해당 UI가 나오지 않는다

(음수 -> 양수) 또는 (양수 -> 음수) 일 경우에만 작동한다

![[Pasted image 20260929141633.png]]

`div` 에 `key` 값을 추가하여 `changeRate` 가 변경될 때마다 `div` 를 다시 렌더링 하도록 하면 해결된다.
